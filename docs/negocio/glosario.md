# Glosario

| Término | Significado |
|---|---|
| **Oferta** | Un producto con precio rebajado que encontró el sistema en una tienda. |
| **Oportunidad** | Una oferta que pasó todas las reglas y deja ganancia real. |
| **Precio de oferta** | Lo que cobra hoy la tienda. |
| **"Precio antes"** | El precio que la tienda dice que tenía antes de la rebaja. Puede estar inflado. |
| **Descuento anunciado** | El que dice la tienda: compara el precio de oferta contra su "precio antes". |
| **Descuento real** | Compara el precio de oferta contra el precio de mercado. Es el que importa. |
| **Precio de mercado** | Lo más barato que un comprador común puede pagar hoy por el producto nuevo (RN-002). |
| **Precio de venta esperado** | A cuánto calculamos venderlo en Amazon, con criterio conservador (RN-002). |
| **Mediana** | El valor del medio de una lista ordenada. Representa el precio "típico" sin dejarse jalar por días raros. |
| **Margen neto** | Lo que queda por unidad después de costos de compra y venta (RN-001). |
| **Margen ajustado** | El margen neto menos lo esperado por devoluciones y por posible baja de precio (RN-005). |
| **Rendimiento mensual** | Cuánto rinde el dinero invertido por mes, considerando cuánto tarda en regresar (RN-005). |
| **Ranking de ventas (BSR)** | Lugar del producto en ventas dentro de su categoría en Amazon. El número 1 es el más vendido; entre más chico el número, mejor se vende. |
| **FBM** | Vender en Amazon guardando y enviando uno mismo el producto. |
| **FBA** | Vender en Amazon enviando el inventario a bodegas de Amazon. No se usará al inicio. |
| **UPC / EAN** | Código de barras del producto. Sirve para reconocer que dos tiendas venden exactamente el mismo modelo. |
| **Keepa** | Servicio de pago que guarda años de historial de precios y ventas de Amazon. |
| **Comisión de Amazon** | Porcentaje del precio de venta que cobra Amazon por cada venta. |
| **Producto restringido** | Producto o categoría que Amazon solo deja vender con aprobación. |
| **Material peligroso** | Productos con reglas especiales de envío (algunos perfumes, aerosoles, baterías). |
| **Liquidación** | Rebaja fuerte para sacar inventario; a veces solo en tienda física. |
| **Confianza del dato** | Qué tan seguro es que el producto esté en la tienda: Alta, Media o Baja (RN-007). |
| **Ruta** | Viaje que junta varias tiendas para repartir el costo del traslado (RN-008). |
| **Tablero** | Pantalla donde se ven todas las oportunidades, aunque no generen aviso. |
| **Inspección** | Revisión de calidad de cada regla antes de construirla. Da un dictamen y preguntas. |
